# IT Service Management Pro

## About
A professional IT Service Management system built with C# and SQL Server for tracking service requests, incidents, and IT operations.

## Features
- Service request management
- Incident tracking and resolution
- Equipment maintenance records
- User management
- Reporting dashboard

## Technologies
- C# (.NET)
- SQL Server
- Windows Forms

## Database
- SQL Server with stored procedures
- Database update scripts included
